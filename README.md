# dps-common-python

Common reusable Python modules for NLNZ Digital Preservation services.

## Installation

Install from GitHub:

```bash
pip install "git+https://github.com/NLNZDigitalPreservation/dps-common-python.git"
```

You can also pin a branch, tag, or commit:

```bash
pip install "git+https://github.com/NLNZDigitalPreservation/dps-common-python.git@main"
```

## Package Contents

- `common.shared`: shared runtime helpers and configuration helpers.
- `common.utils`: common utility modules (HTTP, blob storage, email, process helpers, etc.).
